Second pass (2026-10-07, before the repository went public): internal names were removed from every tracked text file
of the repository, in bb72/ and outside it (the top-level SANITIZE.txt lists the files outside). No number, rule or
result changed. The rules below describe the replaced names without quoting them; each was applied as an exact
replacement:
- Hosts. The Mac mini's nickname became "Apple M4 Mac mini" or "Mac mini", and its three timing session labels
  (nickname-m4-A, -B and -S) became "M4 session A", "M4 session B" and "M4 session S". The Linux workstation's
  nickname, used as a host name, became "Linux workstation". What the first pass had left of the Mac's host name in
  mac_A.log (<user> and the rest of the name) became m4-host, as in the other records.
- The RunPod H100 pod. Its session labels (h100-<pod id>-pre, -post and -preflight) became "H100 session pre",
  "H100 session post" and "H100 session preflight", "RunPod <pod id> (" became "RunPod (", and its GPU UUID became
  GPU-<uuid>.
- Cluster jobs. The RTX session's label, an Alpine job id with the name of an internal note, became "Alpine (CU Boulder
  Research Computing)". The other Alpine and Derecho job ids and job names were dropped: "Alpine <id>" became
  "Alpine" or "an Alpine job", "Derecho <id>" became "a Derecho job", "job <id>" became "an Alpine job", and a list
  of jobs became their number ("three Alpine jobs").
- Internal notes, names and signals. References to internal notes and logs, run names (including another study's
  runs and pod) and coordination signal names were removed, or the sentence was reworded around them. The
  coordinating role became "the study lead", hours of working time in PLAN.md became "working hours", and a row of
  STAGE3_PLAN.md's cost table became "working time". DESIGN.md's header has no byline and gives
  the request that started the study in English only; PLAN.md's Q8 no longer names another project.
- Paths and run names. The work directory of the Mac mini became ~/work (mac_S.sh, and the QND_RELAY default of
  bb/code.py and qldpc_neural/qnd/circuits.py), and the run directory in it became bb72_stage3.
- File names. data/bb/stage3/opp_test_reads_<nickname>.csv became opp_test_reads_workstation.csv.
- The reproductions, outside bb72/. RunPod pod ids became <pod-1> to <pod-6> and network-volume ids <volume-1> and
  <volume-2> (one placeholder per id, numbered within each reproduction), container host names became <container>,
  GPU UUIDs became GPU-<uuid> and a GPU serial number <serial>.
The timing rows (the inputs of bb.stage3 analyze), cells.json and amendment_S.json carry the new session labels, and so
do results.json and results_amendment_S.json: both analyses, run again from this directory, write these two files,
RESULTS_stage3.md, RESULTS_stage3_amendment_S.md, the printed reports (analysis.log, analysis_amendment_S.log) and the
three figures byte for byte. engine.py, net.py and fused.py, which the engine signature hashes, did not change.
